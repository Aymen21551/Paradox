## G. Plan sonore

- **Voix** : passe-haut 80 Hz, débruitage FFT léger, compression 3:1, normalisée à −14 LUFS / −1,5 dBTP (`public/footage/voice.m4a`). Mesuré sur l'export : −14,9 LUFS intégré, −1,1 dBTP.
- **SFX** (générés, libres de droits) : impact (0,1 s), clic (mots clés, webinar, commentaire), whoosh (entrées B-roll, coupe du retake), riser (avant le webinar). Aucun SFX sur un mot important.
- **Musique** : aucune fournie. Si ajoutée (`MUSIC_SRC`) : −20 dB sous la voix, remontée sur la carte de fin, fondu final.
- **Silences** : pauses naturelles conservées sauf le retake coupé.

## H. Montage — réalisé dans Remotion

1. EDL : `0,30–40,60` + `48,45–53,60` (temps source).
2. Recadrages : voir D (`SHOTS` dans `src/data/edit.ts`).
3. Étalonnage : contraste +7 %, saturation +8 %, luminosité −2 %, vignette douce.
4. Export : `npm run build` → `out/reel.mp4`, H.264 CRF 16, AAC, 1080 × 1920, 30 i/s.

Pour CapCut à la place : mêmes points de coupe, mêmes échelles (zoom 118 %, 112 %, 125 %…).
